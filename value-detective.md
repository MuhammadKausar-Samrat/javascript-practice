# Question: Value Detective

Write a function `describeValue` that takes any value
and returns:

`<type of the value> | <truthy or falsy>`

## Examples

| Input | Returns |
|---|---|
| `"hello"` | `string \| truthy` |
| `""` | `string \| falsy` |
| `25` | `number \| truthy` |
| `0` | `number \| falsy` |
| `true` | `boolean \| truthy` |
| `null` | `object \| falsy` |
| `undefined` | `undefined \| falsy` |
