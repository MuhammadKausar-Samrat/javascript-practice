# Problem: Return the Sum of Two Numbers

### Task

Create a function called `addition` that takes two numbers as arguments and returns their sum.

### Examples

| Function Call | Expected Output |
|---|---|
| `addition(3, 2)` | `5` |
| `addition(-3, -6)` | `-9` |
| `addition(7, 3)` | `10` |

### Requirements

- The function must take two numbers as arguments.
- The function must return the sum of the two numbers.
- Don't forget to use the `return` statement.
