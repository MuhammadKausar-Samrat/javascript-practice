# Problem: Encore Total

The crowd wants one more song!

Write a function `encoreTotal` that takes a number of songs and returns the total number of songs after the band adds exactly one encore song.

### Examples

```javascript
encoreTotal(5);   // 6
encoreTotal(10);  // 11
encoreTotal(0);   // 1
encoreTotal(100); // 101
```

### Requirements

- `songs` is a whole number from `0` to `100`.
- The encore always adds exactly one song.
- Return the final total number of songs.
